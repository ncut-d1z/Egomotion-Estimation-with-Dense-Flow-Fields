## 已选决定

| 决定 | 已选行为 | 与旧合同的区别 |
|---|---|---|
| DEC-R6-01 | 两个有限、非零平移方向以 `atan2(norm(cross), dot)` 求角，结果为度；计算前可作防上下溢的等价尺度归一。 | 替代未钳制 `acos` 的浮点实现，消除有限非零方向因单位化点积舍入越界而产生的假无定义；不把零向量改成有效方向。 |
| DEC-R6-02 | 逐帧旋转向量先映射为 `R = Exp(w)`，再比较相对旋转的 SO(3) 测地角，结果为 `[0,180]` 度。 | 替代旋转轴之间的方向角；零旋转向量表示单位旋转，是合法输入。比较每帧旋转增量，不累计成整条轨迹姿态，也不另乘未定义的时间步长。 |
| DEC-R6-03 | 将求解成功与各项指标有效性分开；成功求解产生运动/系数，指标分别携带有效值或完整错误原因。 | 某一指标无定义不再使已经完成的整帧求解回滚；比较求解、主求解或系数策略真正失败时仍不提交任何本帧状态。 |
| DEC-R6-04 | 采用**部分有效结果方案 B**：保留已完成求解产生的全部逐轮指标、缺测位置/原因、有效次数，允许带明确有效性标记交付 `Incomplete` 结果。 | 不采用方案 A；不跳帧，不压缩索引，不删除缺测样本，不把缺测填为零，不改变既定八轮分母。 |

旧源 `normrelfehler.m`、既有历史 MAT 和旧测试报告保持只读及原身份。DEC-R6-02 是所有者选择的**指标语义变化**，不能把新旋转测地角标为历史旋转轴方向角的逐值复现。求解公式、球谐动作、噪声抽样顺序、周期 `1/5/11/21` 及比较系数 `dumi` 的弃置规则保持。

## 指标与 Session 状态

- 平移方向为零仍无定义。非有限或其它不能形成指标的输入保留明确错误，不伪造成功值。
- 两个零旋转向量的 SO(3) 误差为零；零真旋转对非零估计的误差等于估计相对单位旋转的主旋转角，因而可以评价原轨迹中的零旋转帧。
- `AdaptiveFrameResult` 的每个比较槽分别返回平移/旋转指标结果。槽位保持原顺序；指标失败必须保存错误码、阶段、消息及原因链。
- 比较/主求解及策略准备均成功后提交主状态和应提交的周期基线，即使某些指标缺测；时钟推进一次。真实求解或策略失败仍保留原状态和原帧重试能力。

## 聚合和交付

Comparison 的计划重复数仍为八。每个误差单元保留八轮原值及有效性；只有八轮均有效时才按原固定分母八产生有限均值。若任一轮缺测，该单元的聚合值保持缺测，不能改成 `sum / valid_count`。有效次数是额外证据，不是替换聚合分母。`rottransratio` 继续取最后一轮，其有效次数只有 0 或 1，不按八轮平均。

Adaptive 原科学 MAT 字段名、维度、列主序和源端点位置保持。新结果增加：

1. `egomotion_metric_policy.mat`，变量同名，`1×4 double`：`[1,1,1,planned_runs]`，依次标记 schema、平移方向指标、SO(3) 旋转指标及计划重复数。先发布该标记，使不完整发布不会被误认为旧定义数据。
2. 每个源字段 `name` 的 `valid_name.mat`，维度与源字段完全一致，值为对应单元的有效次数。源端点仍为数值零且 count 为零，明确表示未评价端点。
3. 源字段内适用帧缺测以 NaN 表达，并由同形有效次数及 Manifest 原因解释；不允许无有效性标记的 NaN 被当作完整科学值。无穷大不是缺测编码。
4. Manifest 使用 v2，记录指标策略、有效性统计、逐轮原值及缺测原因；JSON 用 `null` 表达缺测，禁止输出非标准 JSON `NaN`。

全部计划求解完成而存在指标缺测时，可交付状态为 `Incomplete`，并保留真实 completed、有效/缺测帧数量及各单元有效重复次数。只有所有适用指标满足计划次数且文件发布/回读证据完整时，才可标记 `Complete`。CLI 对成功发布的两种状态均返回 exit 0，输出实际状态；求解错误仍为 exit 5，输出/审计错误仍为 exit 6。真实求解中止、I/O 或日志故障仍依既有错误合同报告，不能借部分有效模式将失败改称成功。

## 读取、分析与展示

Reader 保留二维 double 载荷及列主序；是否允许某个 NaN 由已验证的指标策略和同形有效次数共同决定。没有新标记的历史目录继续按旧合同解释，不宽泛放行历史 NaN，不改写历史资料。

Analyzer 核对 marker、计划次数、companion 形状、次数范围、端点和有限/缺测一致性，再沿用原取样区间、分段、平滑和列顺序。缺测位置必须留在结果中，JSON 输出 `null` 并提供有效性信息；SVG 在缺测处断线，不跨越缺口连线，也不把无效点画为零。新旧旋转指标必须有明确来源/定义标识，不能混作同一统计量。
