七、保存或载入 JSON

所有数据只在当前浏览器页面中处理，不会发送到服务器。保存文件由你自行选择目录和文件名；页面不能未经授权自行写入 HTML 所在的磁盘目录。

尚未选定文件夹。点击底部“保存”会优先打开浏览器系统保存对话框；请选 HTML 所在的 docs/approval 目录。

关于浏览器保存路径的限制

浏览器不能直接把 HTML 所在文件夹设成无须选择的写入目录。支持 File System Access API 的浏览器可以通过系统“另存为”对话框选择任意合法路径；也可以先点击“选择文件夹”，由你授权写入。若浏览器不支持，页面会下载 JSON，具体位置由浏览器的下载设置决定；请开启“每次下载前询问保存位置”或事后移动到 docs/approval。
