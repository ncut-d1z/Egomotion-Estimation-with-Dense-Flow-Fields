## 真实来源与行为

- getflowfield.m 加载 MAT 后读取 MATLAB load 返回结构的第一个字段；上层经常在路径中省略 .mat 扩展名。该兼容行为不能混同于“按指定变量名严格读取”。
- 当前样本文件头提示 MATLAB 5.0 MAT-file 与 miCOMPRESSED，需 matio+zlib；尚未验证每份 MAT 是否都满足相同格式。
- 数据生成脚本通常将一个变量写入一个同名 MAT 文件（如 xwerte、ywerte1…6、allemitrotfehler 等）。历史归档可能包含当前生成脚本不再写出的文件，应保留该差异信息。

## 候选对象边界

- MatFileHandle 和 MatVariableHandle：唯一拥有底层 matio C 指针，非复制、可移动、析构释放；文件读取错误不能产生资源泄漏。
- MatResultReader：仅公开“列出变量、严格指定变量名、兼容原 getflowfield 读取、读取数值和元数据”等只读能力。
- RunMatWriter：仅写入新 RunId 对应的独立结果目录，需验证路径不位于 origin/** 且不跨符号链接或 ../ 路径逃逸；默认拒绝覆盖既有结果。
- FlowField 等领域值对象从 MAT 读取器接收自拥有数组，不保留悬垂 Eigen Map。

## 必须固定的数据合同

- 变量名、rank、dims、class_type、data_type、压缩/复数标志、字节长度和 MATLAB 列主序。
- 原始数组的 double/single 及高维布局不可静默转换。struct、cell、稀疏、复数、逻辑若真实存在且未支持须明确报错，不能假称解析成功。
- MATLAB 1-based/线性索引与 C++ 0-based 的换算在领域数据边界进行，需独立测试。
- 结果写出与回读要核对变量名、矩阵形状、数值、结果身份；不得更改原始文件哈希。

## 异常状态与检查场景

候选分类：文件不存在/权限不足、无效 MAT 头或压缩、变量不存在、类型不支持、维度不符、长度溢出、非有限数据、输出目录重叠、已有 RunId、写后回读失败。**具体错误枚举与 CLI 退出码尚未冻结**。

- TC-F-MAT-001～004：抽样与全量读取；严格/兼容读取差异；写回读与只读。
- TC-D-MAT-001～003：582 文件全量字典，变量名与矩阵布局。
- TC-I-MAT-001、TC-DC-IO-001：资源生命周期、抽象边界、错误输入、输出路径保护。
