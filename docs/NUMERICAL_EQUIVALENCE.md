## 当前可支持的结论

C++ 工程已有固定输入数学回归、原始 MAT 独立逐值复核、有限端到端运行及错误路径证据。**尚不能认定全部实验数值等价**：三个真实 Adaptive 入口没有完整成功产物，完整 Bias/L4、病态前向误差资格及正式容差尚未完成。CTest 通过包含规定失败、替身编排与 I/O 负例，不能将测试总数当作有效科学样本数。

最新受测源码为 `7f4d248255a1502b65e1f8210071a5d47b919839`，分支 `dev-plan-P0-P1-mat-dictionary-probe`。两模式构建无诊断，**SVG ON66/66、OFF65/65 CTest**；先MAT7项，再59/58项，零失败/跳过/禁用。DirectionSet已封装N×3有限存储/只读访问，复制工厂和显式所有权移交接入采样/光流/球环境；新增901项形状/非有限/值寿命/分配故障检查及移交类型编译断言通过，见 [证据](reviews/R6_DIRECTION_VALUE_2026-11-18.md)。只检查形状/有限性，保留零/非单位有限方向供原物理消费端判定，不归一化或改变面/叶顺序。714行独立采样、运动839项、系数178项及原回归通过；Adaptive注入由36088增至36091以核对三入口错误行索引。FlowField及D4仍缺，后续文档提交不代表重新构建。

实测环境仅 Ubuntu 24.04.5 / Linux 7.0.0-43-generic x86_64、GNU 16.2.0、C++17 Release、CMake/CTest 4.3.4、Eigen 3.4.0、matio 1.5.26、zlib 1.3、Sophus 1.24.6。其它 Debian/Ubuntu 版本和工具链**未验证**；构建耗时不作为性能预算。

## 失败、不可定义和未完成样本

三个真实 Adaptive CLI 的当前结果均为 **Incomplete**，完整重复数为0，没有完整MAT结果。实际规定失败测试通过只证明错误链/计数/原子状态/失败审计正确：

| UpdateRates | MATLAB帧151，同一零旋转角度问题 | 149有效帧；计划1次，完成0 | 完整真实1/5/11/21曲线与当前save集合 |

初始化真实Step本身成功，固定输入重放与原结果按位一致；long double点积舍入为1不能证明真实几何角严格为零。Comparison/UpdateRates的失败不能通过改分母、跳帧或伪造0角度消除。原源码仅静态审阅，没有声称 MATLAB 运行时异常与C++错误码相同。详见 [真实CLI诊断与保留日志](reviews/R6_ADAPTIVE_CLI_2026-11-17.md)。

条件性诊断中，窄锥h=0.1/0.01/0.001的理论条件数分别为1e4/1e8/1e12；历史固定`07f37e2`实测原始解最大分量误差约1.62e-13/7.93e-10/4.16e-6，而后向残差均约1e-17。当前回归仍通过该诊断族，**未批准病态前向误差阈值**。这些运动阶段之后的完整公共单步还会因零投影范数拒绝，不能记为十二个成功Adaptive样本。
