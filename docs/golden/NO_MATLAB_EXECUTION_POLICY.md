# 不再要求运行 MATLAB：数值验收与参考证据的长期政策

> **项目所有者当前明确决定：永久取消将运行原 MATLAB `.m` 脚本作为本项目的设计、实现、Golden 生成、冻结、验收或交付前置条件。** 本文件记录该范围决定，不意味着任何 SRS/LLD/TC 已获验收签字、也不解除 H-10/H-11 对 C++、Bash、CTest、MAT 写入等实际执行的暂缓。未经明确另行授权，本项目不执行 MATLAB 或 Octave；任何后来的自愿参考运行都不能反向恢复为强制前置条件。

## 1. 权威口径与直接后果

1. **不再要求**安装 MATLAB、MATLAB Runtime、运行 `origin/**.m`、插桩或修改原脚本、在 MATLAB 上生成逐轮 `near/t/ω`、R3/R5、RNG、Session/异常轨迹、Golden 或论文曲线。**不得因无法运行 MATLAB 而阻塞 P0/P1、LLD 编码准备或最终验收**。
2. **原 MATLAB 源码仍是算法规范的只读文本依据**；公式、常量、变量布局、循环次序、`save`、MATLAB 列主序/1-based 索引、RNG 调用顺序等可从源码静态审查。不能借此声称特定 MATLAB 版本的实际警告、NaN/Inf 传播、每次随机数及每轮浮点值已经验证。
3. **现有 582 个 MAT 仍是原作者提供的最终结果资料**，可在不运行 MATLAB 的条件下直接只读解析、做类型/文件身份与最终结果对照；它们不含本项目未捕获的内部中间量，不将其伪称原脚本逐节点 Golden。
4. **后续必需参考体系**：L2（原作者归档的最终 MAT 值及其 SHA-256）、L3（由静态源公式、解析推导、独立人工/独立非被测 C++ 实现所得的固定输入数值）、L4（在相同指标、样本分母、噪声定义和有效样本条件下的统计对照）。L3、L4 的证据须实际生成/独立复核、附完整来源和日志；被测 C++ 自己产生的结果不能反填成参考真值。
5. **L1（原 MATLAB 运行逐节点数据）永久退出“必需证据/门禁/待办”列表**。历史证据分级表可保留 L1 一栏以解释缺口，但当前和后续工作不为取得 L1 安排 MATLAB/Octave 运行，也不等待 L1。不存在的 L1 只能标“未取得/本项目不要求”，不能标“已通过”。
6. **精度与验收**：项目所有者已选定 [容差建议](GOLDEN_TOLERANCE_PROPOSAL.md) 中的 `atol=0.01`、`rtol=0.1` **作为第一轮宽松探索性筛查**，**尚未批准用于最终模块 AC/TC PASS 的数值验收阈值**。数量、次序、维度、MAT 数据类型、状态分类、RNG 消耗计数、物理几何不变量仍须单独严格检查。逐模块正式阈值/例外仍由 DEC-005 审定，未签署前不宣称数值测试通过。
7. **原版未可观测运行行为的陈述边界**：不能再以“原 MATLAB 全行为数值完全等价”为发布或验收条件；可按照批准范围报告“静态公式/控制流保真 + L2/L3/L4 独立核对 + 真实 C++ 测试”的限定忠实性。对原 MATLAB 未验证的具体异常警告、随机流、非有限传播与逐轮浮点顺序，必须明确标为“无法证明/未核验”，而不是静默设为等价或无条件通过。
8. **保留其他门禁**：代码/接口/错误状态、原始 `origin/**` 只读、`output/<RunId>/` 安全、实际引入第三方文件时的现有来源/许可告知、SHA-256、CMake/CTest 真实证据及人工基线批准仍须保留；**一般版权复核不再作为原创 C++ 开发的阻塞门禁**，也不据项目 MIT 擅自重新许可原作者独立作品。此长期政策属于**运行需求撤销**，不等于生产代码实施或测试执行授权。

## 2. 现有 AC 的参考来源替换

以下只改变*必须具有“原 MATLAB 实际运行输出”的证据来源前提*；保留算法数学内容、输入、样本范围、索引、输出和未定义值的核验义务。规范性 AC 以更新后的 [SRS §4](../REQUIREMENTS.md) 为准。

|---|---|---|
| `AC-F-FILTER-001` / Franz | 逐轴 MATLAB 实际中间值 | 静态模板公式 + L3 固定输入独立逐节点参考 + 实际 C++ trace/CTest；只能证明覆盖的节点与输入 |
| `AC-F-KVD-001/002` / Original/Modified | MATLAB 逐轮 near/t/ω/次数 | L3 按源公式和精确覆盖顺序独立逐轮参考，另核停止边界、历史 L2 统计；C++ trace/CTest，缺省不可宣称原版逐位等价 |
| `AC-F-GEOM-002/003` / 三种采样 | MATLAB i=0/1/2 有序数值 | L3 按原面表、递归顺序独立构建 i=0/1/2 **所有行**；严格点数和排列，浮点按批准容差 |
| `AC-F-ADAPT-001/002/003` / 单步/Session | 原 MATLAB M1–M4 和跨帧状态 | L3 固定 N×6/3×5、按公式逐节点独立参考、固定帧号模拟；验证 C++ 独立会话/更新次序；不称原 MATLAB 异常逐位等价 |

| `AC-F-FLOW-002/003`、`AC-NF-RNG-001` / 随机与噪声 | 原 MATLAB RNG 实际抽样流 | 固定注入的 uniform/normal 序列及消耗次数 L3，和独立分布/样本数 L4；不要求跨语言同 seed 的原 MATLAB 位序列 |

| `AC-F-AN-001`、`AC-I-ANALYSIS-001` / 分析 | 原 MATLAB begin/end/zone 运行数组 | 从 L2 只读 MAT 经独立重实现的 L3 数值曲线/分段 + 实际 C++/CTest；不要求运行原绘图脚本 |
| `AC-NF-NUM-001/002` / 数值和异常 | 原版奇异/NaN/Inf 的运行响应 | 可静态确定的计算/分支 + L3 解析或独立异常输入 + C++ 明确失败状态和未验证差异记录；绝不宣称原 MATLAB 特定警告/传播已验证 |

## 3. 数值证据保管与状态

每个可执行参考案例至少记录 `reference_level`（L2/L3/L4）、`reference_provenance`、固定输入及来源 blob SHA、参考生成过程/独立审查者、`input_sha256`、`expected_output_sha256`、公式/算法、单位/尺寸/索引、状态、`atol/rtol` 批准来源、对应 REQ/AC/TC/P、C++ 实际输出/CTest/日志及失败/无效分母。解析候选 `AN-G01～12` 仅是起点，不能自动通过。

**效力说明**：历史审批 JSON、早前审查记录中的“等待真实 MATLAB Golden”仅证明当时的方案版本，不再作为当前/后续规范性强制门禁；不修改历史原始审批文件。此决定并未改变“从源码忠实移植 C++”的目标，只撤销了执行原脚本的需求和不可实现的 L1 强制验收前提。后续如要重新引入该前提，须项目所有者另行明确提出。
