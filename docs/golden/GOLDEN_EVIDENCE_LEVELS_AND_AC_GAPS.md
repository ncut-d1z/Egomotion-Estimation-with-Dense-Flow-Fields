# Golden 来源等级与 AC 独立验收矩阵（未冻结草案）

> **长期决策：永久取消运行 MATLAB/Octave 及取得 L1 Golden 的强制要求。** 依据 [无需 MATLAB 运行政策](NO_MATLAB_EXECUTION_POLICY.md)，历史记录中将“缺 MATLAB L1”视为阻塞的判断**全部失效**。本文件不是实际 C++/CTest、数值容差或基线批准记录；只读原 .m 源码、原始 MAT 文件不作修改。

## 1. 证据等级与使用范围

| 等级 | 来源 | 当前事实 | 能否作为强制验收前提 |
|---|---|---|---|
| L1（历史分类） | 原 MATLAB 运行逐节点、RNG、异常和警告 | 未采集，本项目不要求采集 | **否，永久退出必要清单**；也不宣称已获得 |
| L2 | 原作者现有 582 个 MAT 的最终变量和数据身份 | matio 历史记录 582/582 已解码；独立 SHA-256 和逐元素提取未完成 | 在涉及最终值/格式/统计输入的 AC 中按范围使用 |
| L3 | 原源码静态公式和控制流的独立解析/非被测实现参考 | AN-G01～12 为候选，尚无真实 C++ 测试，复杂一般输入与多级采样未全部覆盖 | 在涉及逐节点、旋转、采样、固定随机序列及数值算法的 AC 中按范围使用 |
| L4 | 同指标、样本分母、噪声口径下的独立统计对照 | 历史 L2 可为输入；尚无新的统计实测 | 在涉及汇总复现的 AC 中按范围使用 |

对每条实际参考记录必须包含证据等级、源码 Git blob SHA、输入/输出文件 SHA-256、参考生成方法/独立核查者、shape、单位、索引、样本状态、对应 REQ/TC/AC/P、经过审批的 atol/rtol 和真实 C++/CTest 日志。**被测程序的输出不可冒充独立 Golden。**

不能宣称的事实：原 MATLAB 的实际某次 RNG 数字流、各轮浮点逐位结果、特定版本 warnings、奇异 real(inv(M)) 输出、异常时 NaN/Inf 的精确传播；L2 无法反推出这些量。对此只作范围限制，不以缺失 L1 阻塞可行的 L2/L3/L4 验收。

## 2. 现存 582 MAT 的能力边界

- Bias 560 个 MAT：两类场景各 40 个目录、每个目录七种 xwerte/ywerte1…6；可直接用于 L2 最终结果与 L4 汇总；不含逐轮 KvD、单样本近度、RNG 返回流。
- Adaptive 22 个 MAT：初始化 4、without_errors 5、with_errors 7、many_parameter 6；存储 35×1、600×1、600×4 最终结果，不含 M1～M4、逐帧系数、八次单独结果和状态提交轨迹。
- 历史 alleadap* 和部分 rottransratio 属于无法确认来源的额外产物，不得按当前源脚本擅自补造。
- L2 输入经独立实现得到的分析 begin/end/zone、平滑、分段、曲线是 L3；进一步按共同有效样本统计属于 L4。均无需运行原分析 .m。
- 几何采样的叶方向是三角形三顶点的**归一化重心**而不是多面体原始顶点；递归 i=0、1、2 必须按照原面表生成全量有序方向。

## 3. 缺失的参考改由独立 L3 补齐

| 模块 | 从 L2 不能直接得到的量 | 现行 L3 生成及核验方式 |
|---|---|---|
| Franz/KvD | 每轴模板响应/归一分母、t0/ω0；逐轮 near、sum/sign、a/b/c、旧 t 算 ω、新 t、RMS/delta/grenze、迭代次数与最终尺度 | 根据只读源公式使用独立参考逐轮演算，复核先后赋值、至少六轮和 200 次上限，与 C++ trace 做逐节点对照 |
| Adaptive/Session | near_raw/mean/normalized、M1～M4、rhs、z、t/ω、error=MSE、新 near/系数、帧/周期/主基线状态 | 固定多组 N×6 与 3×5，一般和病态案例，独立生成矩阵与运行时序参考；核验八次平均与最后一次 rottransratio |
| RNG/噪声 | 原 MATLAB 每次具体 uniform/normal 数字及场景生成轨迹 | 注入固定已知 uniform/normal 序列，静态核验调用次数和重置次序；统计结果另作 L4；不要求跨语言同 seed 一致 |
| SHRotation | R0、R3(9)、R5(25) 和九项系数前后及相位 | 解析固定旋转和 Don Williamson 独立参考，核坐标、相位、旋转方向、正交性与第三方许可 |
| 轨迹/分析 | 逐帧局部 t/ω、Rᵀ、端点 zeros、图表分段起止和平滑 | 几何解析与从 L2 MAT 独立重算分析函数，不运行原 MATLAB |
| 异常 | 源版本的具体 warning、NaN/Inf 传播 | 静态审计源分支并设计 C++ 明确错误/拒绝规则的 L3 极值样本；**不宣称未知 MATLAB 运行行为已等价** |
