## 1. L1–L4 的来源和当前状态

| 等级 | 定义 | 当前状态 | 不能据此声称 |
|---|---|---|---|
| **L1 原 MATLAB 运行逐节点/逐调用** | 原脚本在可追溯 MATLAB 版本和合法环境上真实运行，固定输入、逐节点/逐帧/逐次 RNG、警告/失败、source SHA、输出 SHA-256 均保存 | **未采集；当前没有获准 MATLAB 运行证据**。这是条件性不可取得，不是永久不可能 | 不能凭源码阅读/独立重实现宣称取得真实 MATLAB 逐节点输出 |
| **L2 作者历史最终 MAT** | 原始归档 582 个 .mat 中实际存在的最终变量、值、shape 和文件身份 | 历史探针已读取 582/582 的变量元数据；**独立 SHA-256 和逐值参考导出仍待完成** | 不能反推出每次 RNG、KvD/Adaptive 每轮状态、奇异/警告、实验实际种子/版本 |
| **L3 独立解析解/独立重实现** | 有固定输入、公式与来源，可独立复核的计算或独立程序输出 | [AN-G01～12](analytic_golden_candidates.v1.json) 为解析候选，**不是原 MATLAB 运行，也尚无生产 C++ 比较** | 不能冒充 L1；被测程序自身输出不能反填成独立 Golden |
| **L4 统计性对照** | 同实验定义、样本分母/有效性/单位一致的汇总值、曲线/分布 | 已有历史 MAT **可用于未来计算**，本次未执行新的统计计算 | 不能推出逐样本等价、每次迭代/8 次平均具体过程、同 seed 随机值 |

**规则**：证据等级、证据可获取性与 AC 的实测状态分开存档。L2 文件存在不是新的通过记录；L3 公式候选不是原 MATLAB 输出；L4 统计可能性不是已完成分析。**全部 AC 当前仍处于软件未实现/未运行/未验收状态**。

**静态可知 ≠ 运行已证**：源码中的旋转小角分支、反向共线分支、循环条件、部分 uniform/normal 调用次数可通过阅读/推导核对；其真实浮点输出、MATLAB RNG 序列、warning、NaN/Inf 传播、帧状态提交要有 L1 或明确承认未证实。Octave 即使运行也须标成“Octave 输出/独立参考”，**不能升级为 MATLAB L1**。

## 2. 现有归档中缺失的过程证据

| 域 | 需要 L1 的数据 | 当前 L2/L3 只能做到 | 忠实性缺口 |
|---|---|---|---|
| Franz 与 KvD | 每轴原始模板响应/归一分母、Franz t0/ω0；每轮 near/sum/符号、旧 t/新 t、Original/Modified a/b/c、旧 t 下 ω、RMS/delta/grenze、退出原因/次数、最终近度均值缩放 | L3 由公式设计固定场景；L2 Bias 只有最终误差 | **不能证明原 MATLAB 逐轮数值和状态时序等价** |
| Adaptive | near_raw/mean/normalized、M1–M4、6×6、rhs/b、z、t_raw/t_norm、ω、error=MSE、near_new、C_new；Session 主/对照系数每帧前后和刷新/不回写 | L3 AN-G12 仅对称解析个例；L2 保存最终 35/600 行误差 | **不能证明一般输入下逐节点及跨帧状态等价** |
| RNG | 特定 MATLAB 版本/生成器/种子的 rand/randn 实际返回流、每样本距离和噪声、两次播种后的实际值 | 可以从源码静态核对调用点及次数，L3 固定注入序列可测试算法 | **不能证明跨语言同种子逐样本随机序列相同** |
| 异常 | 零范数、奇异/病态 real(inv(M))、acos 越界、非正交或非有限旋转、NaN/Inf 后继续/停止/提交的运行轨迹和警告 | 静态可知部分分支与风险，L3 构造边界算例 | **不能证明与原 MATLAB 的具体异常行为完全一致** |
| 球谐 | 原 MATLAB 对不同 R 的 R0(1)、R3(9)、R5(25)、9 系数前后、非法 R 输出 | L3 AN-G06～08 的部分解析候选、Don Williamson 路线 | **不能证明原 SHRotate 的实际逐元素运行输出** |
| 轨迹/分析 | 实际每帧 t/ω、Rᵀ、奇异处理、原 graph 脚本的 begin/end/zone 及平滑数组 | 解析轨迹、从 L2 独立重算曲线可形成 L3 | **不是原脚本运行时捕获的中间数组** |

**重要纠正**：原 `i=0 采样的 `findeDreiecke.m` 输出为三角形顶点**归一化后的重心方向**，**不是**原多面体顶点本身。AN-G01～03 的 i=0 只是 L3 有序候选；`i=1,2` 原 MATLAB 有序输出仍缺。

## 3. 历史 L2 只能支持什么

- **Bias：560 个 MAT**：occluded/proportional 各 40 个目录，每目录 7 个 `xwerte/ywerte1…6`，可核对最终结果/生成未来 L4 统计，**没有**实际距离/流场、RNG 每次抽样与 KvD 每轮运动。
- **Adaptive：22 个 MAT**：initialization=4，without_errors=5，with_errors=7，many_parameter=6。存在 `35×1`、`600×1`、`600×4` 最终变量；不含 Adaptive 一轮内部量、跨帧系数或八次单独运行分量。当前生成脚本的八次平均、`rottransratio` 最后一次保留规则可以**静态读取源码**，但不能从保存的汇总结果倒推真实运行过程。
- `alleadap*` 与部分 `rottransratio` 属于历史额外字段；来源/当时生成脚本版本未确认，不能将 L2 视作某个未核验版本的 L1。
- 从 L2 独立重算的分析 begin/end/zone、平滑和曲线数组属于 **L3（执行且证据保存以后）**；再计算统计汇总才属于 L4。真实原 graph MATLAB 中间量仍缺 L1。

## 5. 后续取证/降级策略（本轮仅计划）

1. **L2**：在合法、授权的独立环境对 582 MAT 原字节做独立 SHA-256，保存逐元素值的来源/shape/dtype/单位；不修改 `origin/**`。
2. **L3**：核对 AN-G01～12 的解析输入和结果；对于可由 L2 生成的分段、平滑、轨迹，准备独立人工/独立代码对照；如果用 Python/Octave，须明确**不构成生产依赖**，且运行/引入必须另行授权。
3. **L1**：如希望证明原 MATLAB 全面忠实性，最小采集集需含 Franz/KvD 逐轮、Adaptive 逐节点/逐帧、SH R3/R5、各 RNG 返回及实际异常/警告。必须提供 MATLAB/随机生成器版本、固定输入、脚本与采集程序 SHA、stdout/stderr、数值 SHA-256。原 `origin/**` 不变，采集可在隔离审核副本插桩并记录它对输出的潜在影响。
4. **AC 回填**：逐条记录 `golden_level`、`evidence_source`、`source_sha`、`input_sha256`、`reference_output_sha256`、`comparison_scope`、`TC/CTest`、`missing_L1_fields`、`actual_test_status`、`remaining_DEC`。新创建的 **0.01/0.1 宽松容差**只属于 [候选方案](GOLDEN_TOLERANCE_PROPOSAL.md)，未获 DEC-005 批准，不代替结构/状态门禁。
