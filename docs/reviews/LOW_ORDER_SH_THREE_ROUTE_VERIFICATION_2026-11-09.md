## 1. 必须计算的九项，而不是任意高阶球谐

2015论文§2.6.3、附录§5.3、式(59)–(67)的范围是l=0,1,2。用单位方向

\[
\boldsymbol d=(x,y,z)^T=(\sin\vartheta\cos\varphi,\sin\vartheta\sin\varphi,\cos\vartheta)^T
\]

明确极角vartheta、方位角varphi和本模块顺序 `[g0,f1,f2,f3,h1,h2,h3,h4,h5]`：

| 项 | 直接公式 | 2015定位 |
|---|---|---|
| g0 | `1/sqrt(4*pi)` | (59) |
| f1 | `sqrt(3/(4*pi))*x` | (60) |
| f2 | `sqrt(3/(4*pi))*y` | (61) |
| f3 | `sqrt(3/(4*pi))*z` | (62) |
| h1 | `sqrt(5/(16*pi))*(3*z*z-1)` | (63) |
| h2 | `sqrt(15/(4*pi))*x*z` | (64) |
| h3 | `sqrt(15/(4*pi))*y*z` | (65) |
| h4 | `sqrt(15/(16*pi))*(x*x-y*y)` | (66) |
| h5 | `sqrt(15/(4*pi))*x*y` | (67) |

**这些九个直接公式正确。** Wolfram按标准CS复球谐的定义，显式作相位转换后九项差全部为精确零。9×9球面积分Gram矩阵精确为单位矩阵；其相应齐次实体调和多项式Laplacian全部为零。h1的齐次形式是 `sqrt(5/(16*pi))*(2z²-x²-y²)`，只在单位球上等于表内式子。零阶系数本身不等于重建近度：近度常1要求g0的系数为sqrt(4*pi)。

对应[定义/递推验证脚本](../../verification/harmonics/verify_low_order_basis.wl)。定义比较先在0<vartheta<pi得到恒等式；极点由笛卡尔多项式的连续延拓覆盖。C++不通过atan2或除sin(vartheta)计算基函数，因此没有极点角坐标奇异分支。

### 1.1 基函数值的递推，不与旋转矩阵递推混淆

对去除CS相位后的关联Legendre函数，采用

\[
P_m^m=(2m-1)\sqrt{1-z^2}P_{m-1}^{m-1},\quad
P_{m+1}^m=(2m+1)zP_m^m,
\]
\[
P_l^m=\frac{(2l-1)zP_{l-1}^m-(l+m-1)P_{l-2}^m}{l-m}.
\]

归一化 `N_lm=sqrt((2l+1)/(4pi)*(l-m)!/(l+m)!)`，m>0实部/虚部分支再乘sqrt(2)。本次C++把`P_l^m*cos(m phi)`与`P_l^m*sin(m phi)`保持为笛卡尔多项式：p11c=x、p11s=y、p21c=3zx、p21s=3zy、p22c=3(x²-y²)、p22s=6xy，避免极点除法。

**C++这组递推表达与直接公式的九项符号差全部为零。** 该结论不是只在若干方向采样所得。

## 2. 旋转必须先声明对函数的作用

全模块统一采用：

\[
\mu_{new}(\boldsymbol d)=\mu_{old}(A\boldsymbol d),\qquad A\in SO(3),
\quad \boldsymbol a_{new}=D(A)\boldsymbol a_{old}.
\]

因此 `D0=1`、正xyz偶极基的 `D1=A^T`。物体主动旋转、相机反旋等具体业务要由调用方明确传A或A^T；此模块不猜测相机方向，不改变Adaptive/轨迹模块。系数为列向量，分块左乘。该约定还给出 `D(A B)=D(B)D(A)`，故组合检查必须保留非交换先后。

## 3. 路线A：定义直接导出的对称无迹张量

将五项写成 `h_i(d)=sqrt(15/(4*pi))*d^T T_i d`，其中

- `T1=diag(-1,-1,2)/sqrt(12)`；
- `T2=(E13+E31)/2`，`T3=(E23+E32)/2`；
- `T4=diag(1,-1,0)/2`，`T5=(E12+E21)/2`。

它们满足 `Tr(T_i T_j)=delta_ij/2`，因此直接系数矩阵为

\[
D^{(2)}_{ij}(A)=2\operatorname{Tr}\!\left(T_i A^T T_j A\right).
\]

该路线由五个定义多项式的Hessian独立构造，不调用IR或Choi递推，也不把被测输出作为Expected。它为一般合法旋转提供全部25项，不局限z90样本。代码用对称矩阵的逐元素乘积求和实现同一个Frobenius内积。

## 4. 路线B：1996＋1998实递推

论文行坐标轴矩阵须为 `R=A^T`。令P把xyz重排为yzx，则IR一阶块 `B=P A^T P^T`，m顺序为[-1,0,1]。二阶递推以m,n∈[-2,2]构造，内部列分母为4−n²，边界列为12；u、v来自IR96式(8.1)及经核对的表1。

P辅助项采用IR98 Table2的前阶边界±(l−1)，而不是错误地访问前阶±l。零u必须在调用辅助函数之前判断。**l=2所有w精确为0**，不计算W、不扩展到l>2。

IR98 Table2负m的V末平方根印成sqrt(1−delta_(m,-1))，与其更正后的式(6.7)、IR96 Table3和直接定义不一致。本实现采用sqrt(1+delta_(m,-1))，并没有把这一处理伪称为作者另行公布的勘误。x45、m=-1、n=0：正确值sqrt(3)/2；印刷减号给sqrt(3)/4。一般符号验证也明确拒绝这个减号变体。

最后对行列同时重排为2015顺序：一阶零基 `[2,0,1]`，二阶零基 `[2,3,1,4,0]`。这不是默认MATLAB-CS基；后者须显式转换。

## 5. 路线C：1999复递推＋W共轭转换

由Choi等1999式(5.4)/(5.5)独立构造D1=F+iG，输入仍为论文轴矩阵R=A^T。内部列使用式(6.1)，负/正边界列使用式(6.9)/(6.14)，各权重来自式(6.2)/(6.3)/(6.10)/(6.11)，零权重同样先短路。

使用式(8.6)的W及式(8.7)：

\[
D^l_{complex}=(W^l)^\dagger R^l_{real}W^l,
\qquad R^l_{real}=W^lD^l_{complex}(W^l)^\dagger.
\]

C++使用`std::complex<double>`进行等价复乘法，实部/虚部对应论文§VII的H/K运算；转换必须用`adjoint()`。转换后的虚部非有限或超过明确舍入余量会返回失败，不无条件丢弃虚部。最后同样显式重排到2015基顺序。

这是独立运算路线，不是把IR公式换一个函数名重复调用。论文的高阶速度/14位有效数字观察不被拿作本项目的实际性能或double误差验收证据。

## 6. 一般SO(3)的精确符号证明

[完整旋转脚本](../../verification/harmonics/verify_low_order_rotations.wl)令q=(q0,q1,q2,q3)为任意非零实四元数，s=q·q，构造标准齐次四元数矩阵N(q)。Wolfram精确核对

\[
N^T N=s^2I,\quad\det N=s^3,\quad A=N/s.
\]

这覆盖整个SO(3)，包括180°，不只覆盖某个Euler角区间。因为三种二阶公式都是A元素的齐次二次式，可清除非零分母s²，比较关于四个独立q变量的多项式系数。

| 精确核对对象 | 实际结果 |
|---|---|
| 九基：定义→直接式 | 9个差全0 |
| 九基：关联Legendre递推→直接式 | 9个差全0 |
| 9×9球面积分Gram | 81项组成I9 |
| 九个实体多项式Laplacian | 9个全0 |
| IR一阶→直接A^T | 9项全0 |
| Choi一阶→直接A^T | 9项全0 |
| IR二阶→直接张量 | 25项全0 |
| Choi二阶→直接张量 | 25项全0 |
| 五个二阶基的 `h(A d)=D2^T h(d)` | 5个多项式差全0 |
| D2^T D2−I（清分母） | 25项全0 |
| MATLAB布局往返 | 9个差全0 |
| MATLAB→paper转换保留任意系数表示的场 | 1个全系数多项式差为0 |

两个主要脚本和[布局脚本](../../verification/harmonics/verify_low_order_layout.wl)最终都返回`allExact=true`，并设置显式Failure分支；不是空列表计数或打印常量true。结果文件保留实际内核版本、来源检查点和实际失败/限制说明。

这证明**给定定义、域、相位和方向时，采用的精确数学表达式一般性等价**，不证明C++编译器的全部行为，也不是独立证明Wolfram内核无缺陷。

## 7. 不能原样照抄的两处印刷/组合问题

### 7.1 2015第30页的d1²/d2²最后展开互换了h4符号

前页式(66)/(72)定义h4正比x²−y²。正确关系应为

\[
x^2=\sqrt{4\pi/9}\,g_0-\sqrt{4\pi/45}\,h_1+\sqrt{4\pi/15}\,h_4,
\]
\[
y^2=\sqrt{4\pi/9}\,g_0-\sqrt{4\pi/45}\,h_1-\sqrt{4\pi/15}\,h_4,
\]
\[
z^2=\sqrt{4\pi/9}\,g_0+\sqrt{16\pi/45}\,h_1.
\]

PDF第30页末段的前两式反用了h4的符号；Wolfram确认印刷xx实际等于y²、印刷yy实际等于x²。在d=(1,0,0)时可立刻看到前者给0而不是1。**九个基函数式(59)–(67)本身没有因此变错**，错误在后续展开；本轮只记录和验证，不实施其他模块的耦合矩阵代码，也不声明作者已发布该勘误。

### 7.2 MATLAB的基值符号与旧SHRotate不能未经转换混用

原`kugelflfunc2`在m顺序下的一阶是sqrt(3/(4pi))*(-y,z,-x)，二阶负号在yz/xz两项；这本身是合法CS相位约定。新的转换函数显式改变系数的相位和排序，保留同一个标量场。

如果原旧SHRotate的一阶块直接作用于该CS系数，同时把输入r解释为本报告的A，则不满足指定场作用。对mu_old=2+z、A=Rx(+pi/2)，正确场是2+y，而旧直接组合给2−y；在ey处分别为3和1。这个反例揭示**不能混用约定**，不据此宣称论文所有实验结果无效，也不在其他模块静默改掉原调用方向。新API只实现明确且三路证明一致的场作用，不提供会混淆正确性的隐式legacy默认模式。
