# AN-G01～03：零级球面采样行序的源码静态推导（2026-11-08）

> **证据类型：原始源码与手算的符号级一致性审阅。** 不是运行原 MATLAB、独立生成器 L3 数值数据、CTest、Golden 批准或对浮点舍入逐位一致性的证明。输入为原 `erzeugerichtungsvektoren.m`、`erzeugerichtungsvektoren_loch.m`、`richtungsvektoren_icosahedron.m`、`findeDreiecke.m` 的只读源码，比较当前 `docs/golden/analytic_golden_candidates.v1.json` 的 AN-G01/02/03。

## 公式与比较范围

原 `findeDreiecke(x,y,z,iteration,ende)` 在 `iteration=ende=0` 时返回 **三个顶点之和的单位向量**：`(x+y+z)/||x+y+z||`，各输入函数按源码面表原始行次序依次追加。这里不模拟递归 `A/B/C/D` 子面展开，**仅审阅零级的初始面顺序**。每行的后三个光流字段由源 `zeros(N,6)` 保持为零。

记 `φ=(1+√5)/2`、`q=1+2φ`、`D=√(φ²+q²)`，并令 `a=φ/D`、`b=q/D`、`c=1/√3`。JSON 浮点表给出大约 `a≈0.3568220897730899`、`b≈0.9341723589627156`、`c≈0.5773502691896258`，下列结果以**代数符号**列出而不声明运行数值代码。

## AN-G01：完整八面体 8 行

原首八面顺序为 `(p1,p3,p5), (p1,p3,p6), (p1,p4,p5), (p1,p4,p6), (p2,p3,p5), (p2,p3,p6), (p2,p4,p5), (p2,p4,p6)`，其中 `p1=+ez, p2=-ez, p3=+ex, p4=-ex, p5=+ey, p6=-ey`。各行三个轴向向量求和再归一，按原列 x/y/z 得：

| 行 | 零级方向（归一） |
|---:|---|
| 1 | `(c,c,c)` |
| 2 | `(c,-c,c)` |
| 3 | `(-c,c,c)` |
| 4 | `(-c,-c,c)` |
| 5 | `(c,c,-c)` |
| 6 | `(c,-c,-c)` |
| 7 | `(-c,c,-c)` |
| 8 | `(-c,-c,-c)` |

这 8 行符号及次序与 AN-G01 当前 JSON 的 8×6 候选对应；原位后三列仍为零。

## AN-G02：缺损八面体 6 行

`erzeugerichtungsvektoren_loch.m` **不重新排序**：只拼接初始完整八面体的 `2,3,5,6,7,8`，因此相应的有序 6 行是

```text
(c,-c,c), (-c,c,c), (c,c,-c), (c,-c,-c), (-c,c,-c), (-c,-c,-c)
```

与 AN-G02 的 6×6 候选次序对应，而不是先生成 8 行后按任何字典序重排。

## AN-G03：二十面体 20 个初始面

原源码的 `V1,V2,V3` 含 12 个顶点，`F` 是固定 20 行三顶点索引。按 F 的源行顺序逐个求三个顶点和，然后用同一个球面单位化规则，有两种代数形式：`(±a,0,±b)`、`(0,±b,±a)`、`(±b,±a,0)` 或三分量均为 `±c`。逐行是：

| 原 F 行 | 顶点 1-based 索引 | 零级方向（x,y,z） |
|---:|---|---|
| 1 | `1,4,9` | `(-a,0,-b)` |
| 2 | `1,5,9` | `(-c,-c,-c)` |
| 3 | `1,8,5` | `(0,-b,-a)` |
| 4 | `1,8,10` | `(c,-c,-c)` |
| 5 | `1,10,4` | `(a,0,-b)` |
| 6 | `12,2,5` | `(-c,-c,c)` |
| 7 | `12,2,3` | `(-a,0,b)` |
| 8 | `12,3,6` | `(-c,c,c)` |
| 9 | `12,6,9` | `(-b,a,0)` |
| 10 | `12,9,5` | `(-b,-a,0)` |
| 11 | `11,7,10` | `(b,a,0)` |
| 12 | `11,10,8` | `(b,-a,0)` |
| 13 | `11,8,2` | `(c,-c,c)` |
| 14 | `11,2,3` | `(a,0,b)` |
| 15 | `11,3,7` | `(c,c,c)` |
| 16 | `2,5,8` | `(0,-b,a)` |

| 19 | `6,7,4` | `(0,b,-a)` |
| 20 | `6,4,9` | `(-c,c,-c)` |

例如 F 第 1 行 `(1,4,9)` 的顶点和为 `(-φ,0,-q)`，故单位方向 `(-a,0,-b)`；F 第 2 行 `(1,5,9)` 的和为 `-(1+φ)(1,1,1)`，故 `(-c,-c,-c)`。表中其他行按完全相同的静态顶点表规则计算，方向符号和原始 20 行次序与 AN-G03 当前 JSON 的 20×6 候选一致。
